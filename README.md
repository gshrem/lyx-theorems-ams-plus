# Theorems (AMS) Plus

Version 2.0.0 for LyX 2.5 (tested with LyX 2.5.3). Styled theorem environments for Hebrew and English documents.

**Start here:** [Installation and user guide](README.pdf) (in Hebrew).

- `layouts` – the module files. Copy all 12 files as described in the guide.
- `examples` – complete examples in Hebrew and English, as LyX and PDF files.
- `tools` – tools for adding the translations and for converting documents from the old package.
- `translations` – the translations used by the translation tool; keep this folder next to `tools`.

PDF export: File ▷ Export ▷ PDF (XeTeX); see section 3.2 of the guide.
